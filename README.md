# Hypertension

 Project Overview

This project analyzes a hypertension (high blood pressure) dataset to identify patterns, risk factors, and trends related to patients’ health conditions and medication usage.

The goal of this project is to demonstrate data cleaning, exploratory data analysis (EDA), and data visualization skills using Excel to generate meaningful healthcare insights.

.

 Project Objectives

Clean and prepare raw healthcare data for analysis

Identify missing, inconsistent, or incorrect values

Analyze relationships between hypertension and patient variables

Create dashboards and visualizations for decision-making
